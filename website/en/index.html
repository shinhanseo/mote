A FEW THINGS TO KNOW

A few questions.

Why add Mote if Codex already has notifications?

Codex already provides notifications and an Activity view. Mote is an optional companion for people who prefer a small menu-bar presence, grouped nudges, and quick access to waiting work while using other apps. If the built-in experience works for you, you may not need Mote.

How do I update an existing installation?

Quit Mote, open the new DMG, and replace Mote in Applications. Your settings are kept. From 0.4.0, Check for Updates & Install in Settings downloads a signed update, installs it, and relaunches Mote after your confirmation. Users on 0.3.1 or earlier need one manual replacement from this website to receive the updater. Enable automatic checks for new-version notices; installation requires confirmation.

Can I use it without Codex?

Mote is a companion for Codex Desktop. It requires Codex Desktop and its local task records. The public release supports Codex Desktop only. Other AI tools and iPhone integration are not included.

Does Mote send my code to a server?

Task monitoring happens on your Mac. Mote does not send chats or code to a Mote server. Codex’s own AI services and GitHub update checks are separate.

Does Mote approve or answer for me?

No. Mote shows status and opens the relevant chat. You approve requests and answer questions in Codex yourself.

Will it interrupt me all day?

Configure approval, input, completion, and error notifications and sounds. Pause notifications for 30 minutes or leave replies for later. Mote respects macOS Reduce Motion.

Can Codex updates affect monitoring?

Yes. Mote currently relies on Codex Desktop’s local data and private live connection format. Updates may require compatibility fixes. Unsupported formats appear in Mote’s diagnostics.

Is it paid?

Mote 0.4.7 is currently free to download. Source code is public. No paid product or checkout is offered, and future pricing has not been decided.
