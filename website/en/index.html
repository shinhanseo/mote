Usage comes from recent local records and may differ from your actual allowance. Reset notifications refer to scheduled times. Snooze and monitoring require Mote to remain running. This is separate from macOS Focus integration.

A FEW THINGS TO KNOW

A few questions.

How do I update an existing installation?

Quit Mote, open the new DMG, and replace Mote in Applications. Your settings are kept. From 0.4.0, Check for Updates & Install in Settings downloads a signed update, installs it, and relaunches Mote after your confirmation. Users on 0.3.1 or earlier need one manual replacement from this website to receive the updater.

Can I use it without Codex?

Mote is a companion for Codex Desktop. It requires Codex Desktop and its local task records. Other AI tools and iPhone integration are not currently supported.

Does Mote send my code to a server?

Task monitoring happens on your Mac. Mote does not send chats or code to a Mote server. Codex’s own AI services and manual GitHub update checks are separate.

Does Mote approve or answer for me?

No. Mote shows status and opens the relevant chat. You approve requests and answer questions in Codex yourself.

Will it interrupt me all day?

Configure approval, input, completion, and error notifications and sounds. Pause notifications for 30 minutes or leave replies for later. Mote respects macOS Reduce Motion.

Can Codex updates affect monitoring?

Yes. Mote currently relies on Codex Desktop’s local data and private live connection format. Updates may require compatibility fixes. Unsupported formats appear in Mote’s diagnostics.

Is it paid?

Mote 0.4.0 is currently free to download. Source code is public. No paid product or checkout is offered, and future pricing has not been decided.
