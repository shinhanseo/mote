A FEW THINGS TO KNOW

궁금한 점.

Codex 없이도 쓸 수 있나요?

모트는 Codex Desktop의 작업을 살펴보는 보조 앱이에요. 설치된 Codex Desktop과 로컬 작업 기록이 필요합니다. 다른 AI 도구와 아이폰 연동은 현재 제공하지 않아요.

제 코드를 외부 서버로 보내나요?

모트의 작업 감지는 Mac 안에서 이뤄져요. 대화나 코드를 모트의 서버로 보내지 않습니다. 다만 Codex 자체의 AI 서비스 이용과, 직접 누르는 GitHub 업데이트 확인은 별개예요.

자동으로 승인하거나 답변을 보내나요?

아니요. 모트는 상태를 알려주고 해당 대화로 이동시켜 줍니다. 실제 승인과 답변은 Codex에서 직접 해요.

계속 켜두면 시끄럽지 않나요?

승인·질문·완료·오류 알림과 소리를 따로 설정할 수 있어요. 30분 동안 알림을 쉬거나, 답변을 나중에 보기로 남겨둘 수도 있습니다. macOS의 동작 줄이기 설정도 따릅니다.

업데이트 후 감지가 달라질 수도 있나요?

네. 현재 Codex Desktop의 로컬 데이터와 비공개 실시간 연결 방식에 의존합니다. Codex 업데이트에 따라 대응이 필요할 수 있으며, 지원하지 않는 연결 형식은 앱의 진단 화면에 표시해요.

유료인가요?

현재 저장소에서 소스를 확인하고 직접 빌드할 수 있습니다. 유료 상품이나 결제는 아직 제공하지 않으며, 향후 가격 정책도 정하지 않았어요.

작은 먼지가 챙겨둘게요.
